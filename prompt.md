# Build an Aqinode Links Page

Create a premium, minimal, mobile-first link directory for **Aqinode**, an independent AI and SaaS technology company.

The page will serve as Aqinode's central destination for visitors coming from X, allowing them to discover our products, projects, and official platforms.

## Brand Identity

- Brand: Aqinode
- Tagline: Building Now, Shaping What's Next.
- Category: AI & Software Infrastructure
- Visual direction: Minimal, futuristic, technical, premium.
- Primary colors: to be obtained from https://aqinode.com.ng
- Avoid purple gradients, excessive glow, generic AI aesthetics, emojis, and unnecessary decoration.

## Page Structure

### 1. Profile Header
- Aqinode logo or simple typographic brand mark.
- Company name: Aqinode.
- Short description: EXploring the frontiers of AI, engineering intelligent systems, and turning bold ideas into real-world products.
- Tagline: Building Now, Shaping What's Next.
- Subtle animated status indicator.

### 2. Featured Products

Create visually consistent, clickable product cards.

**Plorpy**
- Description: An agentic web development and growth platform.

- Status: On Build.

**Pingix**
- Description: Help AI discover and understand your website.
- URL: https://pingix.aqinode.click
- Status: Available.

**AqiDesign**

Each card should include:
- Product name.
- Short description.
- Small, distinctive icon or monogram.
- Availability indicator.
- External-link indicator.
- Entire card should be clickable when a valid destination exists.

### 3. Official Platforms

Add compact links for:
- Aqinode on X: https://x.com/aqinode_hq
- Aqinode GitHub: https://github.com/aqinode
- Official website: https://aqinode.com.ng

### 4. Footer
- © 2026 Aqinode (year made dynamic, not static).
- Building Now, Shaping What's Next.
- Minimal footer styling.

## Design Requirements

- Mobile-first responsive layout.
- Centered content with a sensible maximum width.
- Dark theme by default.
- Clean typography with strong visual hierarchy.
- Generous spacing without wasting screen space.
- Subtle hover and tap interactions.
- Smooth transitions.
- Accessible contrast and keyboard navigation.
- Fast loading, lightweight assets, and no unnecessary dependencies.

## Technical Requirements

- Build using React TSX.
- No unnecessary backend.
- Keep the code clean, modular, and easy to maintain.
- Use Lucide icons or lightweight inline SVGs.
- All external links must open safely in a new tab.
- Add appropriate SEO metadata and Open Graph tags.
- Add basic click tracking using lightweight analytics if available.
- Ensure the page works properly on mobile browsers.

## Important

This should NOT look like a conventional Linktree page.

Think of it as a tiny, polished extension of Aqinode's official brand identity: understated, technical, confident, and intentional.

Prioritize execution quality over visual complexity. Do not invent products, URLs, testimonials, or social accounts.

The final result should feel like something a serious technology company would proudly put in its X bio.
